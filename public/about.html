О проекте

Это учебное веб-приложение, созданное в рамках лабораторной работы №6.

Используемые технологии

  • Node.js — среда выполнения JavaScript на сервере.
  • Express — фреймворк для создания HTTP-сервера.
  • HTML, CSS и JavaScript — клиентская часть приложения.
  • Manifest и Service Worker — установка приложения и офлайн-кеширование.
